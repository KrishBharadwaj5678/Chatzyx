## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Chatzyx.git
```
    
### 2️⃣ Navigate to the Project

```bash
cd Chatzyx
```
    
### 3️⃣ Install Dependencies

```bash
npm install
```
    
### 4️⃣ Start the Server

```bash
npm run dev
```
