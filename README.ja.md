## <img src="https://github.com/KrishBharadwaj5678/Chatzyx/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| -------------------------- | -------------------------------------------------------- |
| 💬 ランダムチャット | ランダムなユーザーとすぐにチャットして、新しいつながりを作れます |
| 📸 メディア共有 | 画像、動画、PDFファイルを簡単に共有できます |
| ✨ 名前のカスタマイズ | 表示名を変更して、自分らしいプロフィールにカスタマイズできます |
| 👥 アクティブユーザー数 | 現在オンラインのユーザー数をリアルタイムで確認できます |
| 🎨 モダンなUI | シンプルでモダン、そして使いやすいインターフェースを提供します |
| 📱 レスポンシブデザイン | デスクトップ、タブレット、スマートフォンで快適に利用できます |

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Chatzyx.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Chatzyx
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ サーバーを起動

```bash
npm run dev
```
