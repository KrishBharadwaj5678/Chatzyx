## <img src="https://github.com/KrishBharadwaj5678/Chatzyx/raw/main/readme/gifs/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| -------------------------- | -------------------------------------------------------- |
| 💬 Chat Aleatório | Converse instantaneamente com usuários aleatórios e faça novas conexões |
| 📸 Compartilhamento de Mídia | Compartilhe imagens, vídeos e arquivos PDF com facilidade |
| ✨ Personalização do Nome | Altere seu nome de exibição para uma experiência personalizada |
| 👥 Contagem de Usuários Ativos | Veja em tempo real quantos usuários estão online |
| 🎨 Interface Moderna | Desfrute de uma interface limpa, moderna e visualmente atraente |
| 📱 Design Responsivo | Funciona perfeitamente em computadores, tablets e dispositivos móveis |

## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Chatzyx.git
````

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd Chatzyx
```

### 3️⃣ Instale as Dependências

```bash
npm install
```

### 4️⃣ Inicie o Servidor

```bash
npm run dev
```
