## <img src="https://github.com/KrishBharadwaj5678/BrainBoosters/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Chatzyx.git
````

### 2️⃣ Переход в проект

```bash
cd Chatzyx
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Запуск сервера

```bash
npm run dev
```
